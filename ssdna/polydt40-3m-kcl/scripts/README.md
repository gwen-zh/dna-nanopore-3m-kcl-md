# poly(dT)40 scripts

This directory contains the exact code snapshot used to rebuild and simulate
the image-safe dT system. `box180/` contains the reconstructed DNA donor and
the water/ion parameter supplement; the large solvated system is omitted.

`code_sha256.json` records the hashes of the executed job files. The scripts
retain their original cluster paths as provenance; they are not rewritten to
pretend that the GitHub checkout was the execution directory.
