# poly(dA)40 scripts

This directory contains the complete NAMD stage configuration and Slurm
launchers for the retained 50 ns dA run. Static inputs are under `input/`.

Submit the launchers from this directory; they run in `../results/`, so NAMD
outputs remain separated from scripts. The sequence is minimization, heating,
`eq1`, `eq2`, `eq3`, `prod20`, and `prod20to50`. For example:

```bash
cd ssdna/polyda40-3m-kcl/scripts
sbatch prepare.sbatch
```

`analyze_50ns.sbatch` is the archived VMD analysis workflow. The current
periodic-image-aware comparison is generated by
[`../../comparison/scripts/analyze_equal_window.py`](../../comparison/scripts/analyze_equal_window.py).
