# poly(dA)40 results

This directory contains NAMD logs, restart coordinates/velocities, extended
system files and cell trajectories for the 50 ns run.

The large DCD files are omitted from Git and listed with SHA-256 hashes in
[`data-manifest/polyda40_dcd.sha256`](../../../data-manifest/polyda40_dcd.sha256).
Current validated comparison figures and tables are in
[`../../comparison/results/`](../../comparison/results/README.md).

## Analysis figure preview

the matched dT40 window. Open the

for contact maps, distributions, ion/hydration contacts and representative
